# Módulo 1 — Capacitación Sistema VixiOn

Capacitación interactiva del Sistema VixiOn del Instituto de Ojos de Puerto Rico. 16 secciones que cubren fundamentos, arquitectura clínica, tecnologías exclusivas, política RLE vs Catarata, manejo de objeciones, banderas rojas, y evaluación final.

## Demo en vivo

**https://salimperez974.github.io/modulo.1/**

## Stack

HTML standalone — un solo archivo `index.html` con CSS y JS embebidos. No requiere build ni dependencias. Auto-guardado de progreso vía localStorage.

## Edición

Edita `index.html` directamente. Cualquier `git push` a `main` se publica automáticamente vía GitHub Pages.
